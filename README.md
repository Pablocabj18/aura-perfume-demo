# AURA Parfums & Beauty

Demo pública: https://aura-demo-pablo.web.app

Demo de e-commerce de perfumería construida con React, TypeScript, Vite, Tailwind CSS, Motion y React Three Fiber.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run typecheck
npm run build
npm run test:e2e
```

La información de tienda se centraliza en `src/config/store.ts` y el catálogo en `src/data/products.ts`.

AURA es una tienda ficticia creada como proyecto de demostración y no está afiliada ni respaldada por las marcas exhibidas.
